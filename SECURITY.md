# Security policy

## Supported version

Security fixes are provided for the latest published BfCamel CRM release.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Use GitHub's
private vulnerability reporting for this repository. Include the affected
version, reproduction steps, expected impact and any suggested remediation.

We will acknowledge a complete report as soon as practical, investigate it,
and coordinate disclosure after a fix is available. Please avoid accessing,
changing or retaining data that does not belong to you while testing.

## Scope

Reports about authorization, CSRF, SQL injection, stored or reflected XSS,
privacy export/erasure, unsafe file handling and unintended personal-data
exposure are in scope. Legal advice, site-specific consent wording and the
site owner's retention policy are outside the plugin's security scope.
