Native form builder and lightweight CRM for WordPress: forms, submissions, contacts and consent evidence.

== Description ==

BfCamel CRM combines a native WordPress form builder with a lightweight CRM. Version 0.4.1 fixes workflow localization, configurable dashboard links, form layout settings, transactional writes and release validation.

== Changelog ==

= 0.4.1 =
* Fixed the red smoke-test pipeline and removed the misplaced WorkflowService bridge.
* Fixed built-in workflow labels so they follow the current WordPress user locale.
* Fixed custom status and priority dashboard links, colors, fallbacks and slug limits.
* Fixed the one-column form setting and the untranslated CSS-first style label.
* Added transactional form publishing, submission capture, contact synchronization and tag catalog updates.
* Prevented GitHub releases from publishing before source, smoke and JavaScript checks pass.

= 0.4.0 =
* Added configurable workflow settings.
* Added custom statuses and priorities with default values.
* Added automation foundations for form-based workflow rules.
* Added unified tag management architecture.
* Added CSS-first form customization approach.
* Updated plugin metadata for the 0.4.0 release.

= 0.3.2 =
* Added contact editing, internal notes, bulk actions, consent filters, My submissions and selected exports.
