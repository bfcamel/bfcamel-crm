# Export

BfCamel CRM can export contacts and submissions as CSV or XLSX.

## Permissions

Export requires the dedicated `bfcamel_crm_export_data` capability **and** access to the source CRM area:

- Contact export also requires `bfcamel_crm_manage_contacts`.
- Submission export also requires `bfcamel_crm_view_submissions`.

This means export permission alone does not expose a CRM area that the user otherwise cannot access.

## Contact export

The Contacts screen can export the current filtered result set. Selected contacts can also be exported separately.

Contact export includes:

- ID
- Name
- Email
- Phone
- Organization
- Contact status
- Tags
- Personal-data consent status
- Marketing consent status
- Created timestamp
- Updated timestamp

Current consent statuses are resolved from the consent event history.

## Submission export

The Submissions screen exports the current filters, including search, status, form, responsible employee, priority, tag and date range.

Submission export starts with these core columns:

- ID
- UUID
- Form
- Contact
- Status
- Priority
- Responsible employee
- Tags
- Received timestamp
- Source URL

BfCamel CRM then discovers payload field keys across the exported result and adds a `Field: <key>` column for each unique key. Array values such as checkbox selections are flattened into comma-separated text.

## CSV

CSV downloads use UTF-8 with a BOM for better compatibility with spreadsheet applications. Cells beginning with characters commonly interpreted as spreadsheet formulas (`=`, `+`, `-`, `@`, tab or carriage return) are prefixed before output to reduce formula-injection risk.

## XLSX

XLSX files are generated by the plugin's built-in `XlsxWriter` and served as temporary download files. The temporary file is removed after it is sent to the browser.

## Privacy note

CRM exports may contain personal data, submission content, consent states and source information. Limit export capability to users who need it and handle downloaded files according to your organization's retention and access rules.
